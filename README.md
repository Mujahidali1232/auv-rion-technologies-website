## 🛠️ Key Platform Features

1. **Synchronized Global Delivery Mesh**: Real-time multi-timezone clock displaying operational status across Riyadh, Dubai, London, and New York.
2. **Interactive Scope & Architecture Estimator**: Real-time project simulator allowing enterprise C-level leads to configure platforms, regional compliance, squad sizes, and receive an instant blueprint with 1-click brief dispatch.
3. **Enterprise Tech Radar**: Interactive architecture breakdown across Frontend, Backend APIs, Cloud & DevSecOps, Sovereign Data, and Applied AI.
4. **Institutional Case Studies**: In-depth portfolio with verified metrics covering sovereign government portals, private wealth banking, industrial SCADA telemetry, and healthcare interoperability.
5. **Confidential RFP & Brief Suite**: Lead capture system with optional bilateral mutual NDA countersignature guarantees and direct phone dispatch to regional desks.
6. **Executive Dark/Light Visual Language**: High-contrast, glassmorphic floating headers, ambient radial light effects, and responsive layout across all device viewports.

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

```bash
# Typecheck & Lint
npm run lint

# Production build
npm run build
```
